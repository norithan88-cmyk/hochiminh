# ホーチミンナビ

ベトナム・ホーチミン市在住/駐在の日本人、およびホーチミンへの日本人旅行者向けの
生活・観光サポートサイトです。

公開サイト：[ホーチミンナビ](https://hochiminh.sunsun.live/)（準備中）

## 構成
- `hochiminh-navi-pwa.php`：WordPressプラグイン（PWA化、AIラジオの「今日の3行まとめ」自動生成）
- `automation/owner-message.json`：運営者からのひとこと（AIラジオで読み上げ、手動編集）
- `WordPress_TOP_Page_貼り付け用.html`：トップページ本体
- `固定ページ_*.html`：市場ガイド・観光スポット・ベトナム語コピペ集・情報提供フォーム

※ 大気質（PM2.5）自動更新機能は、無料・登録不要の公式APIが見つからなかったため
今回は非対応です（シラチャナビ/プーケットナビとの違い）。
